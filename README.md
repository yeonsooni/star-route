# 성간 개척 일지 — 함장의 항해 (v10)

혼자 하는 우주 항해 브라우저 게임입니다. 채굴, 교역, 전투, 탐사, 제조, 임무, 세력 평판이 들어 있습니다.
v3에서는 화면과 분위기를 고전 SF 우주 드라마 느낌으로 모두 바꿨습니다.
- 함장 시점이고, 승무원이 보고합니다. 항해일지와 탐사 이벤트 카드가 있습니다.
- 세력, 함선, 자원 이름과 그림은 모두 이 게임을 위해 새로 지었습니다. 원작의 고유 용어, 이미지, 로고는 쓰지 않았습니다.
- 그림은 모두 코드(CSS, SVG, Canvas)로 그렸습니다.

## 실행 방법
- **가장 간단하게:** `index.html`을 더블클릭해서 크롬이나 사파리로 엽니다.
- **로컬 서버로 열기:** 이 폴더에서 `python3 -m http.server 8000`을 실행한 뒤 `http://localhost:8000`을 엽니다.
- 인터넷에 올리지 않았습니다. 진행 상황은 이 브라우저(localStorage)에만 저장됩니다.
- v1과 v2 저장 파일도 그대로 이어서 할 수 있습니다. 예전 함선 이름은 새 이름으로 바뀝니다.

## v15에서 바뀐 점
- **줌이 실제 크기를 바꿉니다:** 마우스 휠이나 두 손가락 확대·축소 때, 거리만 벌어지는 것이 아니라 함선·기지·소행성·항성·행성·효과가 같이 커지거나 작아집니다. 기본 배율에서는 예전과 같은 크기이고, 많이 축소하면 작은 표시만 남고, 확대하면 함선이 화면을 크게 채웁니다. 글자 크기는 그대로 읽기 쉽게 유지됩니다. 줌은 부드럽게 움직이고, 커서나 두 손가락 가운데를 기준으로 확대됩니다.
- **함선 모양을 다듬었습니다:** 가늘고 긴 선체에 겹친 장갑판, 한쪽으로 치우친 함교, 옆 포드, 안테나, 창 불빛과 엔진 묶음을 넣었습니다. 함급마다 실루엣이 다릅니다. 원작 그림이나 고유 이름은 쓰지 않았습니다.
- **도킹 장면:** 기지에 들어갈 때, 메뉴가 뜨기 전에 위쪽 큰 화면에 격납고 문이 열리고 내 함선이 들어오는 짧은 3D 장면이 나옵니다. 카메라는 자리에 서서 함선 머리를 따라 살짝 오른쪽으로만 돕니다. 화면을 누르면 건너뛸 수 있고, 이미 기지 메뉴로 돌아올 때는 나오지 않습니다.

## v14에서 바뀐 점
- **워프가 끊기지 않아요:** 워프 진행을 화면 프레임(경과 시간)에 맞춰 부드럽게 하고, 가속·감속도 부드럽게 이어집니다. 속도 줄기는 미리 만들어 둔 입자로 가볍게 그립니다.
- **우주 함선이 진짜 3D로 돌아요:** 납작한 그림이 돌아가는 대신, 정비고와 같은 3D 함선이 방향·선회(기울기)에 따라 원근이 보이게 그려집니다. 워프 때는 뒤에서 본 모습입니다. 3D가 안 되는 기기에서는 예전 그림이 나와요.
- **조명:** 항성 쪽에서 오는 빛으로 한쪽은 밝고 반짝이며, 반대쪽은 어두운 금속(건메탈·청동)으로 남고, 가장자리에 차가운 림 라이트와 작은 엔진 궤적이 있어요. 크기는 v13과 같습니다.

## v13에서 바뀐 점
- **우주 함선 모습:** v12에서 너무 크고 밝았던 내 함선을, 별빛에 한쪽만 옅게 밝힌 어두운 금속 회색-푸른 선체로 낮추었어요. 큰 후광은 빼고 얇은 림과 작은 엔진 불빛만 남겨, 어두운 우주에 있는 배처럼 보이게 했어요. 크기는 예전(v11)에 가깝고, 휴대폰에서만 아주 작아지지 않게 최소 크기를 두었어요. 다른 세력 함선도 같은 방식으로 차분하게 맞추고, 강조색만 살짝 다릅니다.
- **워프:** 속도 줄기가 모이는 소실점 쪽으로 함선이 조금 작아지며 빨려 들어갑니다. 도착하면 제자리와 크기로 돌아와요. 배 뒤에서 따라가는 시점은 그대로예요.

## v12에서 바뀐 점
- **우주 화면 함선이 더 잘 보여요:** 정비고 3D 함선을 우주에 그릴 때 선체를 밝은 은회색으로 올리고, 가장자리에 얇은 림 라이트와 부드러운 후광, 뒤쪽 엔진 불빛을 넣었어요. 작은 화면에서도 너무 작아지지 않게 최소 크기를 두었어요. 게임 규칙은 그대로예요.
- **다른 함선:** 방위군·상인 약탈선·넥서스 함선도 같은 방식으로 윤곽이 살아나게 했고, 강조색(파랑·청동·녹색)은 다르게 두어 내 함선과 구별돼요.

## v11에서 바뀐 점
- **거리 표시:** 가까운 구역(기지, 암석, 근처 함선)은 m·km로, 성계의 항성·행성과 워프 거리는 AU로 보여요. 우주 화면의 동심원 눈금(5·10·20·40 km)은 근접 구역만 가리키고, 항성·행성은 그 바깥의 성계 영역에 AU로 표시돼요. 목록·선택 정보·워프 거리도 같은 방식으로 맞춰 두었어요. 게임 규칙(워프가 필요한 거리, 채굴·전투 사거리)은 그대로예요.
- **우주 화면 함선:** 정비고에서 보던 3D 함선 모습을, 우주 화면에 위에서 살짝 내려다본 그림으로 넣었어요. 여러 각도를 미리 그려 두고 진행 방향에 맞춰 돌려요. 3D가 안 되면 예전 함선 그림이 나와요.
- **메뉴 아이콘:** 기지 메뉴(출항, 기지, 함선 정비고, 교역소, 임무, 스킬, 성계도, 설정 등)와 휴대폰 아래 탭에, 가는 선(1.5px)으로 그린 도면·계기판 느낌의 아이콘을 넣었어요. 바깥 아이콘 라이브러리는 쓰지 않았어요.

## v10에서 바뀐 점
- **워프 연출:** 워프 정렬 동안 함선이 목적지 쪽으로 천천히 몸을 틀고, 이어서 카메라가 함선 뒤로 돌아가요. 화면이 진행 방향이 위로 오게 돌고, 함선은 아래 가운데에 놓여요. 별과 성운이 빛줄기가 되어 흘러가고, 워프 터널을 지나 도착하면 감속하며 원래 화면으로 돌아와요.
- **활동별 교육 과정:** 기본 과정(12단계) 말고도 기본 조작·이동, 채굴, 무역, 전투, 임무, 장착·업그레이드, 함선 정비, 스킬, 탐험·워프·항성도, 세력 과정이 있어요. 그 활동을 처음 할 때 저절로 시작되고, 설정 → [교육 과정]에서 골라 다시 볼 수도 있어요(끝낸 과정에는 ✓ 표시). 오래 멈춰 있으면 힌트가 나오고, 어느 과정이든 [과정 그만두기]로 끌 수 있어요. 처음 끝낸 과정마다 10,000 LM을 받아요.
- **휴대폰 아래 칸 끌기:** 손잡이(또는 요약 줄)를 끌어 올리면 펼쳐지고, 끌어 내리면 접혀요. 손을 떼면 가까운 높이(접힘·반·크게)에 붙고, 빠르게 튕기면 그 방향으로 가요. 목록 안에서 끌면 목록만 움직이고, 손잡이를 톡 눌러도 접고 펼 수 있어요.
- **함선 정비고:** 예전 격납고가 함선 정비고가 됐어요. 한 화면에서 [상태](보호막·장갑·선체, 속도, 화물칸, 장착 슬롯, 수리·보험), [튜닝](장비 달고 떼기), [보관함], [함선 구매]를 할 수 있어요. 위쪽에는 함선이 3D로 보이고, 끌면 좌우·위아래로 돌고, 두 손가락이나 휠로 확대돼요. 손을 떼면 천천히 저절로 돌아요. 사려는 함선도 3D로 미리 볼 수 있어요. 3D는 바깥 라이브러리 없이 직접 만들었고, 3D가 안 되는 기기에서는 예전 함선 그림이 대신 나와요.
- 휴대폰 우주 화면에서는 교육 안내가 한 줄 카드로 떠서, 전투 중에도 우주가 넓게 보여요(눌러서 펼침).

## v9에서 바뀐 점
- **새 게임 흐름:** ① 시놉시스(별이 흘러가는 배경 위에 한 줄씩 나타남, 화면을 누르면 넘어감, [건너뛰기]) → ② 게임 소개 카드 6장(탐험 · 전투와 세력 · 무역 · 채굴과 제조 · 임무 · 함선과 스킬) → ③ 부함장 튜토리얼. 설정에서 [시놉시스 다시 보기]를 할 수 있어요.
- **휴대폰 우주 화면:** 아래 판은 기본으로 접혀 한 줄(지금 하는 일 + [멈춤] 또는 [기지로 귀환] + [목록 ▲])만 보여요. 튜토리얼이 목록을 눌러야 할 때만 저절로 펼쳐지고, 끝나면 다시 접혀요.
  - 부함장 안내는 두 줄짜리 작은 배너예요(누르면 펼쳐짐). 임무 목표는 한 줄 칩이고, 튜토리얼 중에는 배너와 합쳐져요. 눈금 안내 줄은 휴대폰에서 없앴어요. 장비 바도 더 얇아졌어요.
  - 사파리 아래 주소창을 뺀 390×664 화면에서 우주가 보이는 높이가 약 70~75%예요.
- **부함장:** 이름은 Evan, 남성 초상화로 바꿨어요. 안내 말투는 짧은 보고체예요(예: "함장님, 채굴 빔 가동 중입니다. 화물칸 84/150㎥. 만재 시 보고드리겠습니다.").
- **우주 배경:** 성계마다 다른 성운·은하 사진풍 배경 4종(`img/space/`, 어둡게 처리)이 아주 천천히 움직여요. 별은 두 배로 촘촘해졌고, 밝은 별에는 십자 빛갈래가 있어요.
- 컴퓨터 화면의 배치는 그대로예요(우주 배경·시놉시스·말투·부함장만 공통으로 바뀜).

## v8에서 바뀐 점 — 다른 기기에서 이어하기가 쉬워짐
- **이어하기 링크:** 설정 → [이어하기 링크 보내기] → 에어드롭·메모·나에게 보내기로 다른 기기에 보냄 → 다른 기기에서 링크를 누르고 [확인]하면 이어서 할 수 있어요.
  - 진행 내용은 링크의 `#` 뒷부분에만 들어 있어요. 이 부분은 웹 서버로 전송되지 않아요. 불러온 뒤에는 주소창에서 바로 지워요.
  - 게임을 인터넷 주소(https)로 열었을 때만 버튼이 보여요. 파일로 열면 링크가 다른 기기에서 열리지 않기 때문이에요.
- **짧은 코드:** [짧은 코드 복사] → 다른 기기의 설정 칸(또는 첫 화면)에 붙여넣고 [코드로 불러오기]. 파일로 열었을 때도 돼요.
  - 예전 긴 코드는 약 10만 자였는데, 짧은 코드는 약 4천~8천 자예요(진행할수록 조금씩 늘어요).
  - 줄인 방법: 압축(deflate, 브라우저 기본 기능) + 시장 재고를 2% 단위로 저장(가격 차이 1% 안팎). 다른 진행은 모두 그대로예요.
- 예전 긴 저장 코드와 저장 파일도 그대로 쓸 수 있어요. 받는 칸에는 링크·짧은 코드·긴 코드 무엇이든 붙여넣으면 돼요.
- 서버·클라우드·외부 서비스는 전혀 쓰지 않아요. 바깥 라이브러리도 넣지 않았어요.
- 함장 이름 기본값은 "함장"이에요. 검색 엔진에 뜨지 않도록 `noindex`를 넣었어요.

## v7에서 바뀐 점 — 휴대폰에서도
- 컴퓨터 화면(가로 1280 이상)은 v6 그대로입니다. 설정 화면에 "다른 기기로 옮기기" 칸만 새로 생겼습니다.
- 휴대폰(아이폰 세로 390×844 기준, 가로 모드도 됨)에서는 배치가 바뀝니다.
  - 왼쪽 메뉴 → 화면 아래 탭바. 옆으로 밀면 메뉴가 더 나옵니다. 맨 앞은 [출항].
  - 위쪽 바는 한 줄: 자금 · 위치 · 함선 상태 · 버튼.
  - 화면들은 세로로 한 줄씩 쌓입니다.
  - 우주에서 오른쪽 목록은 아래에서 올라오는 판이 됩니다. 손잡이를 누르면 접히고 펼쳐집니다. 장비 버튼판은 [접기]로 줄일 수 있습니다.
  - 누르는 곳은 높이 44px 이상입니다.
- 손가락 조작(우주 화면)
  - 톡 누르기: 선택 · 두 손가락 벌리기/모으기: 확대/축소 · 한 손가락으로 끌기: 둘러보기([가운데]로 되돌림)
  - 꾹 누르기(0.5초), 또는 [이동]을 누른 뒤 톡: 그곳으로 이동 (컴퓨터의 더블클릭과 같음)
- 아이폰 사파리: 화면 확대·튕김 막음, 노치/홈바 피해서 배치, 첫 터치 뒤 신호음 켜짐, 저장은 그대로 이 기기 안(localStorage)
- 홈 화면에 추가하면 앱처럼 열립니다(아이콘은 게임 그림으로 만들었습니다). 인터넷 주소(https)로 열었을 때만 오프라인 저장(sw.js)이 켜집니다. 파일로 열면 꺼져 있습니다.
- 기기 간 저장 옮기기: 설정 → [저장 코드 복사] → 메시지·메모로 다른 기기에 붙여넣기 → 다른 기기의 설정(또는 첫 화면)에서 [코드로 불러오기]. 파일로 옮겨도 됩니다([파일로 공유·저장]).

    - 노랑 → 머스터드
  - 꽉 찬 색 면 대신 반투명한 바탕에 얇은 테두리를 썼습니다. 엘보 장식도 가늘게 바꿨습니다.
  - 지금 고른 메뉴와 핵심 버튼만 조금 더 진하게 표시됩니다.
  - 위험·경고 색과 보안 등급 뱃지도 덜 쨍한 색으로 바꿨습니다.
- **그림:** 기지, 함선, 항성, 행성을 도형 그림에서 일러스트로 바꿨습니다. 그림은 `img/sp/`에 있고, 18장을 합쳐 약 435KB입니다.
  - **내 함선:** 원반부와 나셀이 달린 모양입니다. 함급에 따라 소형, 호위, 순양, 중(4나셀) 그림을 씁니다.
  - **방위군:** 별도 그림을 씁니다.
  - **적 함선:** 세력마다 모양이 다르고, 큰 배와 작은 배 그림이 따로 있습니다.
    - 골드렉 상인 조합: 청동 화물 약탈선
    - 넥서스 합일체: 검은 결정체 배
  - **기지와 관문:** 기지는 천천히 돌고, 도킹할 때 출입구에 불이 켜집니다.
  - **행성 6종:** 용암, 가스, 얼음, 사막, 청록 바다, 보라 밀림입니다. 빛 받는 쪽이 항성을 향하도록 돌아갑니다.
  - **항성:** 하나의 항성 그림을 성계마다 그 항성 색으로 물들여 씁니다.
  - 그림을 불러오지 못하면 예전 도형 그림으로 보입니다.

## v5에서 바뀐 점
- **메뉴 색감을 차분하게 바꿨습니다.** 고친 곳은 왼쪽 메뉴, 그 아래 빈 블록, [출항] 버튼, 위쪽 바뿐입니다.

  - 지금 보고 있는 메뉴만 조금 더 진하게 표시됩니다.
- 본문 패널, 우주 화면, 대화창, 성계도의 색은 그대로입니다.

## v4에서 바뀐 점

  | 기지 | 창밖으로 항성과 행성이 보이는 라운지 |
  | 교역소 | 화물 상자와 진열대가 가득한 상가 홀 |
  | 격납고 | 함선이 정박한 거대한 격납 베이와 크레인 |
  | 장착 | 정비 도크에서 로봇 팔이 장비를 다는 함선 |

  | 스킬 | 격자무늬 훈련 시뮬레이터 |
  | 항성도 | 별지도 관측실 |

  - 그림을 흐리게 하고 가장자리를 어둡게 했으며, 그 위에 어두운 막을 씌워서 글자가 잘 읽힙니다.

## v3에서 바뀐 점
- **화면:** 검은 바탕에 주황, 라벤더, 하늘, 황토색 블록을 쓰고, 둥근 팔꿈치 모양 테두리와 번호 라벨을 붙였습니다. 이모지 아이콘은 모두 없앴습니다.

- **그림:**
  - 항성과 무늬가 있는 행성 6종(용암, 얼음, 가스, 암석, 바다, 밀림)을 그렸습니다.

## 기본 흐름
1. **[출항]** → 오른쪽 [이동(워프)] 탭에서 **소행성대**로 [워프]합니다.
2. 소행성을 고르고 **[채굴 시작]**을 한 번 누르면 화물칸이 찰 때까지 자동으로 캡니다.
3. **[기지로 귀환]**을 누르면 자동으로 도킹합니다. 그다음 **[화물 모두 판매]**를 누릅니다.
4. **임무 본부**에서 임무를 받아 루멘과 평판을 법니다.
5. **[성계도]**를 열고 "?" 행성을 탐사해 보세요.

## 파일
- `index.html`, `styles.css`
- `js/data.js`: 데이터
- `js/core.js`: 규칙, 행성, 탐사 이벤트, 저장
- `js/space.js`: 우주 시뮬레이션
- `js/courses.js`: 활동별 교육 과정
- `js/ship3d.js`: 함선 정비고 3D 보기와 우주 화면용 함선 그림(WebGL, 바깥 라이브러리 없음)
- `js/sprites.js`: 함선·기지·행성·항성 그림을 돌리고 키워서 그립니다.
- `js/art.js`: 그림(승무원 초상화, 항성, 행성, 함선, 기지)과 신호음
- `js/ui.js`: 화면
- `img/space/`: 성계 배경 그림 4장
- `img/`: 기지 화면 배경 그림 10장, 앱 아이콘 3개(`icon-180/192/512.png`), `img/sp/`: 함선·기지·행성·항성 그림 18장
- `manifest.webmanifest`: 홈 화면 앱 설명서, `sw.js`: 오프라인 저장(https에서만)
